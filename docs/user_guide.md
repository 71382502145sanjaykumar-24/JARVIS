# JARVIS User Guide & Interaction Manual

## 1. Interacting with JARVIS

JARVIS supports two input modalities simultaneously:
1. **Voice Input (Push-to-Talk):**
   - Click the central **🎙 ACTIVATE VOICE** button.
   - Speak your command clearly into your microphone.
   - JARVIS will transcribe your utterance, process the intent, display the response, and speak it aloud.
2. **Text Input:**
   - Type commands or questions into the command bar at the bottom of the dashboard.
   - Press **Enter** or click **TRANSMIT**.

## 2. Command Reference & Examples

### 2.1 Conversational & AI Queries
- *"Hey Jarvis, how are you?"*
- *"Explain artificial intelligence in simple terms."*
- *"What is the difference between supervised and unsupervised learning?"*
- *"Write a Python script to sort a list of dictionaries."*

### 2.2 Application Launching & Closing
- *"Open Notepad"*
- *"Open Calculator"*
- *"Open File Explorer"*
- *"Open Command Prompt"*
- *"Close Notepad"*

### 2.3 Web Browsing & Search
- *"Open YouTube"*
- *"Open Google"*
- *"Open GitHub"*
- *"Search for Python tutorials on Google"*
- *"Search for space exploration videos on YouTube"*

### 2.4 System Diagnostics & Information
- *"What time is it?"*
- *"What is today's date?"*
- *"System status"* (Reports real-time CPU %, RAM utilization, and battery state)

### 2.5 Voice & Safety Controls
- *"Stop talking"* or *"Be quiet"* (Immediately stops speech synthesis)
- *"Emergency stop"* or clicking **🛑 EMERGENCY STOP** (Halts active desktop automations and sound output)

## 3. Configuration & Settings Panel
Click **⚙ SETTINGS** on the top right to access:
- **AI Intelligence:** Enter or update OpenAI API keys, select model (`gpt-4o-mini`, `gpt-4o`, `gpt-3.5-turbo`), and test connection status live.
- **Voice & Audio:** Adjust speech rate (WPM), volume slider, toggle speech responses ON/OFF, and test audio samples.
- **Automation & Safety:** Enable/disable desktop automation, toggle confirmation dialogs, and inspect approved application registries.
- **System & Memory:** Clear conversation history and reset configuration.
